# 10 minutes guide

## Introduction

`filterx` is a command line tool to filter lines from files. It is inspired by [grep](https://www.gnu.org/software/grep/) and [awk](https://www.gnu.org/software/gawk/) and [bioawk](https://github.com/lh3/bioawk).

### Features
- 🚀 Filter lines by column-based expression
- 🎨 Support multiple input formats e.g. vcf/sam/fasta/fastq/gff/bed/csv/tsv
- 🎉 Cross-platform support
- 📦 Easy to install
- 📚 Rich documentations


## Installation

## Quick Start

This section provides a brief overview of `filterx`'s capabilities. We'll use this sample CSV file for many examples:

```csv title=example.csv
name,age
Alice,20
Bob,30
Charlie,40
```

### Basic Filtering

Filter rows where age is greater than 25. If your file has a header, use the `-H` flag.

```shell
filterx csv example.csv -H -e 'age > 25'

# Output
# Bob,30
# Charlie,40
```

For files without headers, use `col(index)` to refer to columns (0-indexed).

```shell
# Assuming example-no-header.csv is example.csv without the header
filterx csv example-no-header.csv -e 'col(1) > 25'

# Output
# Bob,30
# Charlie,40
```

Combine conditions using `and` or by providing multiple `-e` flags. To keep the header in the output, use `--oH`.

```shell
filterx csv example.csv -H --oH -e 'age > 25 and name == "Bob"'
# Output
# name,age
# Bob,30
```

### Column Manipulation

`filterx` provides powerful functions to manipulate columns.

**Select columns:** Use `select` to choose which columns to output and in what order.

```shell
filterx csv example.csv -H --oH -e 'select(age, name)'
# Output
# age,name
# 20,Alice
# 30,Bob
# 40,Charlie
```

**Create new columns:** Use `alias` to add a new column.

```shell
filterx csv example.csv -H -e 'alias(age_plus_10) = age + 10'

# Output
# Alice,20,30
# Bob,30,40
# Charlie,40,50
```

**Rename columns:** Use `rename` to change a column's name.

```shell
filterx csv example.csv -H --oH -e 'rename(name, person_name)'

# Output
# person_name,age
# Alice,20
# Bob,30
# Charlie,40
```

### Row Manipulation

**Get the first N rows:** Use `head`.

```shell
filterx csv example.csv -H -e 'head(1)'

# Output
# Alice,20
```

**Get the last N rows:** Use `tail`.

```shell
filterx csv example.csv -H -e 'tail(1)'

# Output
# Charlie,40
```

**Drop rows with missing values:** Use `drop_null`.

```csv title=missing.csv
name,age
Alice,20
Bob,
,30
```

```shell
filterx csv missing.csv -H --oH -e 'drop_null(age)'

# output
# name,age
# Alice,20
# ,30
```

### String and Sequence Manipulation

**Get string length:** Use `len`.

```shell
filterx csv example.csv -H -e 'len(name) > 4'

# Output
# Charlie,40
```

**Extract with Regex:** Use `extract` to get parts of a string.

```csv title=names.csv
name
Alice-20
Bob-30
```

```shell
filterx csv names.csv -H -e 'alias(age) = extract(name, "(\d+)")'

# Output
# name,age
# Alice-20,20
# Bob-30,30
```

**Bioinformatics Example:** Calculate GC content and sequence length.

```fasta title=bio_example.fasta
>seq1
ATGC
>seq2
GATTACA
```

```shell
filterx fasta bio_example.fasta -e 'print("{name}\tGC={gc(seq)}\tlen={len(seq)}")'

# Output
# seq1	GC=0.5	len=4
# seq2	GC=0.2857142857142857	len=7
```

### In-place Editing

Functions ending with an underscore (`_`) modify the data directly (in-place). For example, to convert a sequence to its reverse complement:

```shell
filterx fasta bio_example.fasta -e 'revcomp_(seq)'

# Output
# >seq1
# GCAT
# >seq2
# TGTAATC
```

### Advanced Output Formatting

Use `print` with f-string like syntax to create custom outputs. You can even call other functions inside `print`.

```shell
filterx csv example.csv -H \
     -e 'age > 25' \
     -e 'print("{name} is {age} years old. Name length: {len(name)}")'

# Output
# Bob is 30 years old. Name length: 3
# Charlie is 40 years old. Name length: 7
```

## Functions

### Column

#### alias
While add a new column to the table, the new column name must be wrapped in `alias()` function. `alias` need a column name as argument, and only can be used in create column statement. 


```csv title=test.csv
a,b
1,2
3,4
```

create a new column named `c` with value `a + 1`:

```bash title="example"
filterx c -H test.csv -e "alias(c) = a + 1"

# output
a,b,c
1,2,2
3,4,4
```

#### cast
Convert values in a column to another type. `cast` need be invoked with the `cast_type` and `column_name` as arguments.

```csv title="test.csv"
a,b,c
a,1,1.1
b,2,2.2
c,3,3.3
```

```bash title=Example1
filterx csv -H --oH test.csv -e 'cast_str_(b);alias(a) = a + b'

# Output
a,b,c,d
a,1,1.100,a1
b,2,2.200,b2
c,3,3.300,c3
```

#### col
Select a column by `name` or `index`.

For a csv with header, you can directly use the column name to select the column.


```csv title="data.csv"
name,age
Alice,30
Bob,25
```



```bash title="Example1"
filterx csv data.csv -H --oH -e "select(col(name))"

# Output:
name
Alice
Bob
```

For a csv without header, you can use the column index to select the column. The index starts from 0.


```csv title="data.csv"
Alice,30
Bob,25
```

```bash title="Example2"
filterx csv data.csv --oH -e "select(col(0))"
# Output:
Alice
Bob
```

`col` can also be used to select multiple columns by using regex.

```csv title="data.csv"
a1,a2,a3,b
1,2,3,4
5,6,7,8
```

```bash title="Example3"
filterx csv data.csv --oH -e "select(col('^a\d+$'))"

# Output:
a1,a2,a3
1,2,3
5,6,7
```

#### drop_null
drop rows with null values


```txt title="test.csv"
name,age
Alice,20
Bob,
,30
```

```bash
filterx csv test.csv -H --oH -e 'drop_null(age)'

# output
name,age
Alice,20
,30
```

allow multiple columns

```bash
filterx csv test.csv -H --oH -e 'drop_null(age, name)'

# output
name,age
Alice,20
```

if no column is specified, it will apply to all columns, any row with null value will be dropped

```bash
filterx csv test.csv -H --oH -e 'drop_null()'

# output
name,age
Alice,20
```

#### dup
Duplicate items in a column(s). There are 4 functions:

- `dup` - Duplicate items in a column and keep the first occurrence.
- `dup_last` - Duplicate items in a column and keep the last occurrence.
- `dup_any` - Duplicate items in a column and keep any one occurrence.
- `dup_none` - Duplicate items in a column and keep no occurrence.


```csv title="data.csv"
name,country
Alice,USA
Bob,UK
Alice,Canada
Alice,USA
```

```bash title=Example
filterx csv -H --oH data.csv 'dup(name)'

# Output
name,country
Alice,USA
Bob,UK
```

`dup` supports multiple columns.

```bash title=Example
filterx csv -H --oH data.csv 'dup(name, country)'
# Output
name,country
Alice,USA
Bob,UK
Alice,Canada
```

#### fill
fill value if the value is null or na. There are another two functions `fill_null` and `fill_na` which are aliases of `fill`.

- `fill_null`: fill value if the value is null.
- `fill_na`: fill value if the value is na.
- `fill`: same as `fill_null`.

```txt title="test.csv"
name,age
Alice,20
Bob,
Charlie,30
```

```bash
filterx csv test.csv -H --oH -e 'fill_null_(age, 0)'

# output
name,age
Alice,20
Bob,0
Charlie,30
```

#### is_null
filters rows with NULL values or not

- `is_null` : filter rows with NULL values
- `is_not_null` : filter rows without NULL values



#### occ
filterx rows by occurence

`occ` is a function that filters rows by the number of times a value occurs in a column.

- `occ_lte`: less than or equal to the number of times a value occurs
- `occ_gte`: greater than or equal to the number of times a value occurs
- `occ`    : same as `occ_gte`

```csv title="data.csv"
a,b,c
1,2,3
2,2,1
2,2,3
2,1,3
```

```bash title="Example1"
filterx csv -H --oH data.csv 'occ(a, 2)'

# Output
a,b,c
2,2,1
2,2,3
2,1,3
```

`occ` supports multiple columns.

```bash title="Example2"
filterx csv -H --oH data.csv 'occ_lte(a, b, 1)'

# Output
a,b,c
2,2,1
2,2,3
```



### Sequence

#### gc
Compute the gc content of a sequence

```fasta title="test.fa"

```


#### hpc
compute the HPC of a sequence, compress contiguous identical characters into a single character

```fasta title="test.fa"

```

```bash title="example"
filterx fa test.fa -e "hpc_(seq)""

# output
>seq1

```

#### phred
Check the quality of a sequence using the Phred algorithm.

There are two kinds of Phred scores: phred33 and phred64.

```fastq title="test.fq"
@seq1
ATGC
+
IIII
@seq2
ATGCC
+
IIIII
```

```bash title="example"
filterx fq test.fq -e "phred()"

# output
phred: phred64
```

#### qual
Compute the mean quality of a sequence.

```fasta title="test.fq"

ATGC
+
IIII
@seq2

+
IIIII
```

```bash title="example"
filterx fq test.fq -e "print('{name}: {qual(seq)}')"
```

```bash title="output"

seq2: 3.9658952
```

### String

#### extract
Extracts a substring from a string by using a regular expression.

```csv title="test.csv"
name
Alice-20
Bob-30
```

```bash
filterx csv test.csv -H -e 'alias(age) = extract(name, "(\d+)")'

# Output
name,age
Alice-20,20
Bob-30,30
```

#### len
Compute the length of a string.

```fasta title="test.fasta"
>seq1
ACGT
>seq2
AGCTGGG
```

```bash title="Example1"
filterx fa test.fasta -e "print('{name}	{len(seq)}')

# output
seq1	4
seq2	7
```

#### lower
Converts a string to lowercase.

```fasta title="test.fasta"
>seq1
ACGT
>seq2
AGCTGGG
```

```bash title="Example1"
filterx fa test.fasta -e "print('{lower(seq)}')"

# output
acgt
agctggg
```

```bash title="Example2"
filterx fa test.fasta -e "alias(lower_seq) = lower(seq)" 
                      -e "print('{lower_seq}	{seq}')"

# output
acgt	ACGT
agctggg	AGCTGGG
```

#### replace
Replace substring with another pattern. There two kind of function: `replace` and `replace_one`. The difference between them is that `replace` will replace all occurrences of the substring, while `replace_one` will replace only the first occurrence.


```fa title="test.fa"
>seq1
AAGGAACC
```

```bash title="Example1"
filterx fa test.fa -e "replace_(seq, 'A', 'G')"

# output
>seq1
GGGGGGCC
```

```bash title="Example2"
filterx fa test.fa -e "replace_one(seq, 'A', 'G')"
# output
>seq1
GGGGAACC
```

There are also support for regular expression.

```csv title="test.csv"
a
apppppple
apple
```

```bash title="Example3"
filterx csv -H --oH test.csv -e "replace_(a, 'p{3,}', 'pp')"

# output
a
apple
apple
```

#### rev
Gets the reverse of a string.

```fasta title="test.fa"

ATCG
```

```bash title="Example"
filterx fa test.fa -e "rev_(seq)"

# output
>seq1
GCTA
```

#### slice
Extract a substring from a string.

```fasta title="test.fa"
>seq1
ACGTCTGATGCATCTAGTCTACAG
```

```bash title="Example1"
# get the first 5 characters
filterx fa test.fa -e "slice_(seq, 5)"

# output
>seq1
ACGTC
```

```bash title="Example2"
# get sub sequence start from 1 with length 5
filterx fa test.fa -e "slice_(seq, 1, 5)" # offset starts from 0, so 1 is the second character

# output
>seq1
ACGTC
```

#### strip
Remove prefix/suffix pattern from string. There are another two functions that can be used to remove only the prefix or suffix: `lstrip` and `rstrip`.

```fasta title="test.fa"

```

```bash title="Example1"
filterx fa test.fa -e "strip_(seq, 'A')"

>seq1

```

```bash title="Example2"
filterx fa test.fa -e "lstrip_(seq, 'A')"
# output
>seq1

```

```bash title="Example3"
filterx fa test.fa -e "rstrip_(seq, 'A')"
# output
>seq1
AAGTCG
```
